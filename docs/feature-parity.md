This matrix is the implementation ledger for the qBittorrent 5.2.3 stock WebUI and Web API 2.15.1. It is populated from the exact release source, not inferred from another Alternative WebUI.

The source tree and target-branch changelog win if the general wiki differs. In particular, qBittorrent 5.2.3 uses `torrents/start` and `torrents/stop`; it does not require the legacy pause/resume names shown in older API material.

`qB 5.0 / API 2.11.2` below is the project's compatibility baseline, not necessarily the historical version in which a long-standing endpoint first appeared. A later API number is shown when the target-branch changelog identifies the feature addition or contract change. Every such feature must be selected through the capability registry rather than raw version checks in components.

## Status and test legend

- **Implemented**: the named user-facing behavior has a usable code path.
- **Partial**: a usable slice exists, but one or more behaviors named in the row are absent or materially incomplete.
- **Not implemented**: no usable user-facing path exists; an API wrapper or capability key alone does not count.
- **Not exposed by target API**: intentionally not simulated for Web API 2.15.1.
- **Automated test** names evidence that has passed. `None` means no focused automated evidence exists for that row; it does not negate source inspection. The current full checkpoints are 24 files / 229 Vitest tests and 63 passed / 81 intentional Playwright project skips across Chromium, WebKit, and the configured mobile/tablet projects. Current round-2 local amd64 and both hosted baseline architectures passed their HIGH/CRITICAL scans; a local content digest is not a registry reference.

The statuses describe the round-2 working tree dated 2026-09-01, based on commit `a266f0f339087547edaacace316a322a348f0a7c`. Mock E2E evidence is not live-daemon verification, and a partial status remains partial even when its implemented slice has a passing test. “Real qB 5.2.3” below means the standalone suite in `container/test-qbittorrent.sh`, not a claim about every Vue control or another qBittorrent version.
