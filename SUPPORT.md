# Support

Bitwake is a community open-source project maintained on a best-effort basis.

## Where to ask

Use GitHub Issues for:

- reproducible Bitwake bugs;
- focused feature requests;
- documentation errors;
- compatibility regressions with supported qBittorrent/Web API versions.

Before opening an issue, search existing issues and review the relevant documentation.

## What is out of scope

The Bitwake issue tracker is not a general qBittorrent, Docker, Kubernetes, reverse-proxy, VPN, storage, or home-network support forum.

If the problem also occurs in qBittorrent's stock WebUI or API, report or discuss it through qBittorrent's own channels unless Bitwake needs a compatibility workaround.

Do not post secrets, cookies, tracker passkeys, private torrent metadata, private file paths, or private network information.

## Security

Do not use ordinary issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Commercial support

No commercial support, response-time SLA, or warranty is currently offered by the Bitwake project. The software is provided under the terms of the `AGPL-3.0-or-later` license.
